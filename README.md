# AgentShield 🛡️

AI Agent Reliability Engineering Platform

## Features
- 🔥 Action Firewall with risk scoring
- 🎯 Dynamic adversarial scenario generation
- ⚡ Chaos Mode testing
- 📊 Before/After fix verification
- 📈 Reliability scorecards

## Quick Start

### Prerequisites
- Python 3.11+
- API keys: Groq, Together AI

### Installation
```bash
git clone https://github.com/your-username/agentshield
cd agentshield
python -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt
pip install -r frontend/requirements.txt
